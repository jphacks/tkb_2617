# 家具組み立てガイド

家具の組み立て説明書（PDF）を読み込み、組み立て手順を3Dモデルとステップ表示で確認するWebアプリです。
説明書のPDFを画面上で確認しながら、現在の組み立て工程、使用する部品、部品の取り付け位置を視覚的に確認できます。

## 製品概要

「家具組み立てガイド」は、家具の組み立て説明書PDFをAIで読み取り、部品の構成と組み立て手順を3Dモデルとして表示するWebアプリです。説明書を読むだけでは把握しにくい部品の向きや取り付け位置を、3D空間上で確認しながら組み立てられます。

## 背景（製品開発のきっかけ、課題等）

家具の組み立て説明書は、複数の部品記号、寸法、イラスト、矢印などの情報が一度に掲載されており、初めて組み立てる人には「どの部品を、どの向きで、どこに取り付けるのか」が分かりにくいという課題があります。特に、紙の図面だけでは完成形を立体的に想像しにくく、工程を飛ばしたり、部品を取り違えたりする可能性があります。

そこで、説明書の情報をAIで構造化し、部品の配置と工程を3D表示することで、説明書を読む負担と組み立て時の迷いを減らすことを目指しました。

## 製品説明（具体的な製品の説明）

ユーザーが家具の組み立て説明書PDFを読み込むと、アプリが説明書の画像から家具名、部品一覧、部品の種類・寸法・個数、組み立て手順を抽出します。抽出した情報をもとに、Three.jsで板材、脚、棒材、ネジなどの3Dモデルを生成し、部品の配置関係から組み立て後の状態を再構成します。

画面では、左側に工程の説明と操作ボタン、中央に3Dモデル、右側に元のPDFを表示します。工程を進めると、該当する部品が強調され、取り付ける位置へアニメーションします。音声操作にも対応しており、「次」「戻る」「もう一回」「再生」「停止」などの発話で操作できます。

## 特長

### 1. 特長1：説明書をAIで構造化

PDFの図面から、家具名、部品記号、部品名、個数、寸法、部品の種類、取り付け関係をJSONとして抽出します。レイアウト解析と工程解析を分けることで、部品の全体配置と手順の情報を整理して扱えます。

### 2. 特長2：部品の関係から3D配置を自動計算

「天板の下」「側板の左側」などの面情報、軸方向、端からの距離をもとに、部品の座標・向き・配置を計算します。左右・前後に複数ある部品は配置を反転して補完し、説明書に詳細な座標がなくても3Dモデルを構成できます。

### 3. 特長3：工程に合わせた視覚・音声ガイド

現在の工程で使う部品を色やラベルで強調し、取り付け方向を矢印で表示します。工程に対応したPDFページも同時に表示できるため、3D表示と元の説明書を照らし合わせながら作業できます。音声読み上げと音声操作にも対応しています。

## 解決出来ること

- 説明書の平面的な図から完成形を想像する難しさ
- 部品記号と実際の部品の対応を確認する手間
- 部品の向きや取り付け位置を間違えるリスク
- 現在どの工程を作業しているか分からなくなる問題
- ネジや小さな留め具の位置・向きを確認しにくい問題
- 手がふさがっている状態で説明書を操作しにくい問題

## 注力したこと（こだわり等）

- AIの出力をそのまま3D表示するのではなく、部品の種類、寸法、向き、取り付け面、配置関係を中間データとして整理し、安定して表示できるようにしました。
- 寸法の単位がmmの場合とcmの場合を判定し、3D空間で見やすい大きさに正規化しつつ、画面上のラベルには説明書本来の寸法を表示するようにしました。
- ネジなどの小さな部品は、実寸のままだと見えにくいため、画面上で確認できる最小サイズを設けています。
- 説明書の情報だけで配置を解決できない場合にも、机・テーブルの天板と脚から基本配置を推定するフォールバック処理を用意しました。
- 解析結果をキャッシュし、同じPDFを何度も解析する場合の待ち時間とAPI利用量を抑えました。

## 使い方

1. 「PDFを選択」から家具の組み立て説明書を選びます。
2. 家具タイプを選択します。
3. 必要に応じて、部品一覧・寸法のページを入力します。
   - 例: `3`
   - 複数ページ: `3,5`
4. 必要に応じて、設計図・組立手順のページを入力します。
   - 例: `4-6`
5. 「説明書を解析」を押します。
6. 解析が完了したら、「戻る」「次へ」で工程を移動します。
7. 音声操作を使う場合は「音声操作 OFF」を押してONにし、「次」「戻る」「もう一回」と話しかけます。

部品ページと設計図ページを指定しない場合、PDFのテキスト情報は全ページから読み取られます。
図面画像として解析するページは、1回につき最大12ページです。

## 解析方式

### オフライン解析（現在の画面で使用）

現在のWeb画面では、家具タイプを選択してPythonベースのオフライン解析を実行します。
PDFの文字情報、図面、部品名、寸法、ネジなどの留め具情報を解析し、
家具プリセットに対応する3D部品と工程データを生成します。

オフライン解析には次のファイルを使用します。

- `server.js`: `/api/analyze-offline` を提供
- `../files/offline_analyze.py`: PDF解析のエントリーポイント
- `../files/extract_assembly_offline.py`: PDF内容の抽出処理
- `furniture-presets.json`: 家具タイプ、部品形状、標準寸法、工程の定義

### LLM解析API

`/api/analyze` は、OpenAI互換のチャット補完API、またはローカルOllamaに接続できます。
PDFのページ画像とテキストをモデルへ送り、モデルのJSON応答を家具プリセットへ変換します。

`.env` を `furniture-guide` ディレクトリに作成し、接続先に応じて設定します。

```dotenv
LLM_BASE_URL=https://api.example.com/v1
LLM_API_KEY=your-api-key
LLM_MODEL=your-model-name
```

Ollamaを使用する場合の例です。

```dotenv
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=
LLM_MODEL=qwen2.5vl:7b
```

Ollamaでは、画像解析が必要な場合に画像対応モデルを使用してください。
APIキーや秘密情報をGitへコミットしないでください。

## API

### `POST /api/analyze-offline`

PythonでPDFを解析します。

リクエスト例:

```json
{
  "pdfBase64": "data:application/pdf;base64,...",
  "furnitureType": "side_table"
}
```

### `POST /api/analyze`

OpenAI互換APIまたはOllamaを使用して、ページ画像とPDFテキストを解析します。

主な入力項目:

```json
{
  "images": ["data:image/jpeg;base64,..."],
  "text": "PDFから抽出したテキスト",
  "imagePages": [3, 4],
  "partsPages": [3],
  "designPages": [4, 5],
  "furnitureType": "side_table"
}
```

解析結果には、家具名、部品一覧、部品サイズ、工程、各工程で移動する部品の位置・回転が含まれます。

## プリセットと単位

`furniture-presets.json` の寸法単位はcmです。
部品サイズは次の形式で定義します。

- 箱形部品: `[幅, 高さ, 奥行]`
- 円柱部品: `[直径, 高さ]`

プリセットには、サイドテーブル、棚、デスク、椅子、引き出し収納、その他の標準形状と組み立て位置が定義されています。
家具の種類を追加・変更する場合は、`furniture-presets.json` の `furniture_types` を編集します。

## 注意事項

- 解析結果は説明書の構成や画質に左右されます。3D表示は組み立ての補助であり、安全確認や部品の最終確認を代替するものではありません。
- PDFのページ指定は1始まりです。ページ範囲は `開始-終了`、複数指定はカンマ区切りで入力します。
- 図面画像の解析対象は最大12ページです。ページ数が多い場合は、部品一覧と組立手順のページを絞ってください。
- オフライン解析の実行には時間がかかる場合があります。サーバー側のタイムアウトは3分です。
- 音声認識の対応状況はブラウザによって異なります。
- `server.js` のオフライン解析スクリプトのパスは、現在の作業環境（`../files/offline_analyze.py` に相当する配置）を前提にしています。別の場所へ移動する場合は `OFFLINE_SCRIPT` の設定を変更してください。
- `cache/` には解析結果が保存されます。入力PDFや設定を変更しても古い結果が表示される場合は、該当するキャッシュファイルを削除してください。
